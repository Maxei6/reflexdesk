# Third-party notices

ReflexDesk source code is MIT-licensed.

Third-party libraries, model runtimes, model weights, tokenizers, and bundled assets remain subject to their respective licenses.

Before any model is distributed in an official ReflexDesk model pack, record:

- exact repository/model identifier
- exact revision or checksum
- license
- commercial-use restrictions
- redistribution requirements
- source URL
- runtime/quantization source
- attribution requirements

Do not infer that a model inherits the ReflexDesk MIT license.

See `models/registry.json`.

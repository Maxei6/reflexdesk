# P0 — Desktop productization

P0 turns ReflexDesk from a developer MVP into a background desktop utility.

## Product lifecycle

### First run

ReflexDesk shows onboarding only when setup has not passed.

1. choose a primary speech language
2. grant microphone access
3. prepare and validate the local Nemotron runtime
4. pass a real end-to-end voice test: **“Hello ReflexDesk”**
5. persist the measured local STT latency and mark setup complete

The normal dashboard is not considered ready until that test succeeds.

### Normal startup

After setup:

- the main window starts hidden
- ReflexDesk lives in the system tray
- the local speech engine prepares in the background
- the global shortcut remains unavailable for successful listening until the runtime is actually ready
- a watchdog restarts the speech engine if it dies
- closing the settings window hides it instead of quitting the service
- the explicit tray **Quit ReflexDesk** action stops owned child processes

A second ReflexDesk instance does not create another speech engine; it brings the existing settings window forward.

## Simple dashboard

Normal users see:

- current state
- one Talk / Stop button
- language
- start-at-login
- Reflex animation toggle
- offline / online-AI permission
- detected AI agents

STT/provider/model endpoints are hidden under **Advanced**.

## Reflex overlay

The listening indicator is a small transparent window placed at the bottom-center
of the monitor containing the mouse pointer.

State color is semantic:

| State | Color |
| --- | --- |
| ready / idle | white |
| listening | cyan |
| hearing speech | bright cyan |
| transcribing | blue |
| reasoning | violet |
| executing | electric violet |
| success | green |
| warning | amber |
| error | red |

The overlay is click-through. Turning listening off stops microphone tracks and
the AudioContext before the window hides.

Microphone capture uses an AudioWorklet instead of ScriptProcessorNode.

## Local speech service hardening

CrispASR no longer uses a fixed local port.

Every speech-engine start:

- reserves an ephemeral loopback port
- generates a random per-session API token
- starts the HTTP server on 127.0.0.1
- authenticates every transcription request
- verifies that /health reports the Nemotron backend

This avoids collisions and prevents ReflexDesk from silently talking to an
unrelated local service.

## Owned processes

ReflexDesk tracks child AI-harness processes that it launches and terminates
those owned sessions when the user explicitly quits ReflexDesk.

Apps opened as user tools (Chrome, Spotify, VS Code, etc.) are deliberately not
owned and are not killed on quit.

## Hardware-aware setup

P0 selects between the portable/legacy x86-64 runtime based on CPU instruction
support and uses the native macOS runtime where Metal support is built upstream.
The onboarding voice proof records real local inference latency.

Automatic download/selection of Windows/Linux CUDA or Vulkan runtime packs is
still a follow-up because bundling every accelerator runtime would add hundreds
of megabytes. It should be selected after a hardware benchmark, not guessed.

## Realtime Nemotron decision

CrispASR exposes a Nemotron realtime WebSocket API, but its current realtime
listener binds to all network interfaces and does not apply the HTTP API-key
check.

ReflexDesk therefore **does not enable that listener in P0**.

The safe current path is:

```text
AudioWorklet -> local utterance boundary -> authenticated loopback HTTP -> Nemotron
```

Execution occurs only after a short speech-final boundary. A future direct
native/localhost-authenticated streaming transport can replace this without
changing the desktop UX.

## Release-security blockers

Preview installers are intentionally unsigned.

A public stable release still requires external release credentials:

- Windows code-signing certificate
- Apple Developer ID certificate + notarization credentials
- Tauri updater signing key/public key
- stable update endpoint / GitHub release metadata

Those secrets must never be committed to the repository.
